AgentFEM Documentation Site

AgentFEM documentation is written as linked Markdown files. The current recommended static-site layer is MkDocs because it is simple, friendly to research software, and easy for agents to inspect.

Local Preview

From the repository root:

cd agentfem
mkdocs serve

Then open the local address printed by MkDocs.

Static Build

cd agentfem
mkdocs build

The generated site is written to agentfem/site/.

Dependencies

For a polished local site:

pip install mkdocs mkdocs-material pymdown-extensions

For a dependency-free static site:

python build_docs.py

This writes a simple HTML site to agentfem/site/.

Documentation Rule

Human-facing docs and agent-facing docs should share the same concepts. When a workflow concept changes, update:

  • README.md
  • WORKFLOW.md
  • CONCEPTS.md
  • docs/module_map.md
  • skills/agentfem/
