# Workflow Reference

AgentFEM workflow:

1. Mesh
2. Function spaces
3. Fields and states
4. Constitutive laws
5. Constraints
6. Loads
7. Boundary models
8. Forms
9. Assembly
10. Solve or time step
11. Diagnostics
12. Output

Do not collapse these steps so aggressively that a reviewer cannot see the
finite-element model.

Use `examples/` as executable workflow references after identifying the target
problem type.
