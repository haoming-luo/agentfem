# Trust and operations

AgentFEM distinguishes a completed computation from an accepted scientific
result. Operational records, numerical checks, benchmark evidence, and known
applicability boundaries stay attached to the workflow.

## Four questions

1. **Did it run?** Inspect process and structured solver status.
2. **Did the numerical method behave?** Inspect convergence, stability,
   equilibrium, energy, conservation, and requested outputs.
3. **Is the method appropriate?** Inspect material/procedure maturity,
   assumptions, mesh regime, and benchmark envelope.
4. **Can the result be traced?** Inspect project, source, mesh fingerprint,
   dependency, artifact, and restart identity.
